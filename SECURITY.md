# Security Policy

## Reporting a Vulnerability

Please report security issues privately before opening a public issue. Use a
GitHub Security Advisory if it is available for this repository, or contact the
maintainers directly.

Include:

- affected firmware version or commit
- board model and flash method
- steps to reproduce
- expected and actual behavior

Do not post provisioning diagnostic logs publicly without reviewing them first.
They can include local WiFi, DHCP, route, proxy, and device status details.

## Scope

This repository contains ESP32 firmware and flashing scripts for LampGo devices.
The default provisioning access point password is documented for first-time
setup and should not be treated as a private secret.
